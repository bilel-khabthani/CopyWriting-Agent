# Portfolio - AdScript Studio

9 échantillons prêts à envoyer comme **échantillon gratuit** à un prospect.
Chaque fichier est un livrable réaliste, généré puis retouché à la main.

- Les 5 premiers couvrent le format **video ad** (accroche, problème, solution,
  appel à l'action + shot list).
- Les 4 derniers montrent les autres formats : **landing page**, **online ad**,
  **email / newsletter** et **sales letter**.

| Fichier | Format | Secteur | Langue | Plateforme |
|---|---|---|---|---|
| `le-jardin.pdf` | Video Ad | Restaurant | FR | Instagram Reels |
| `pulsefit.pdf` | Video Ad | Salle de sport | FR | TikTok |
| `botaniqa.pdf` | Video Ad | Cosmétique bio | FR | Instagram Reels |
| `quickfix-mobile.pdf` | Video Ad | Réparation téléphone | EN | TikTok |
| `fitloop.pdf` | Video Ad | Application fitness | EN | YouTube Shorts |
| `atelier-lumen.pdf` | Landing Page | Cours de poterie en ligne | FR | - |
| `snapchef-adcopy.pdf` | Online Ad | Meal kit | EN | Facebook + Instagram |
| `maison-olive-email.pdf` | Email / Newsletter | Épicerie fine | FR | - |
| `taxflow-letter.pdf` | Sales Letter | Logiciel de comptabilité | EN | - |

- Version **PDF** : à envoyer au client (générée par `exporter.py`).
- Version **Markdown** (`.md`) : pour copier-coller rapidement.
- Régénérer tout : `python samples/build_samples.py`

## Comment utiliser un échantillon
1. Choisissez le fichier le plus proche du produit du prospect (ou générez-en un sur mesure avec le bot).
2. Joignez le PDF au premier message (voir `../marketing/dm-templates.md`).
3. Si le prospect répond, préparez un livrable à son nom avec le bot (`/start`).
